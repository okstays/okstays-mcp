# Security

Please report security issues privately to hello@okstays.com with "Security" in the subject, not in a public issue.

We acknowledge reports within 1 business day (Central European Time) and keep you updated until the issue is fixed.

Scope: the hosted OKstays MCP server at https://okstays.com/api/mcp and the okstays.com website. This repository
holds only documentation and configuration; the server code is not public.
